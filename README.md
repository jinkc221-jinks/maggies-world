# Maggie 的小世界

一片可以走进去的柔软小村庄。五座小屋开着门，种子要亲手从柜子里拿到田里，照片由村里的三脚架相机拍下。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址即可。打包部署用 `npm run build`，产物在 `dist/`。

## 操作

- 电脑：WASD 或方向键移动，Shift 跑步，拖动画面旋转视角，滚轮拉近，空格跳跃，E 互动，Esc 退出拍照或面板，M 打开地图
- 手机：左下摇杆移动，把摇杆推满会跑步，滑动画面旋转，右侧按钮跳跃和互动

种花要走进花园小屋，拿起柜子上的种子，走到门外田里放下，再回去拿水壶浇水。过一会儿花会开，可以收获。

拍照走到村子里的三脚架前，看相机上的小屏幕，按 E 快门。照片贴在旁边的墙上，也保存在这台浏览器里。

右下角是网易云网页播放器，游戏本身不播放背景音乐。

## 小屋

小屋登记在 `src/data/houses.ts`。新增一间时补上 `HouseId`、位置和颜色，门口会自动留出。屋内互动点写在 `src/world/places.ts` 和 `src/components/Interactions.tsx`。

照片、愿望信和田地进度只保存在当前浏览器。
